# Document Responsibilities

| File | Responsibility | Must Not Contain |
|------|----------------|------------------|
| character_bible.md | Core identity | Detailed implementation rules |
| appearance.md | Visual design | Personality and dialogue |
| personality.md | Values and thinking | Speech patterns |
| speech.md | Speaking style | Personality and interaction rules |
| interaction.md | Conversational behavior | Teasing philosophy |
| teasing.md | Teasing rules and boundaries | General interaction behavior |

## Principle

Each document owns one responsibility.

If a topic belongs to another document, reference it instead of duplicating it.

Avoid duplicated definitions to keep future maintenance simple.
